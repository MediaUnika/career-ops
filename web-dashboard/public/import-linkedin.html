Import LinkedIn job matches

LinkedIn has no public API for its personalized job search, so this reads what's already rendered in your own logged-in browser tab — no automated login, no scraping your account in the background.

1. Install the bookmarklet (one-time)

📥 Import to Career Ops

Drag this button up to your browser's bookmarks bar. (If the bar is hidden, show it first — Ctrl+Shift+B in Chrome/Edge.)

2. Use it

  1. Go to linkedin.com/jobs and run your search (or open "Jobs for you").
  2. Make sure CareerOps.exe is running (the dashboard should be open in another tab).
  3. Click the Import to Career Ops bookmark.
  4. It reads every job card visible on the page and adds new ones straight into your pipeline inbox. You'll get a popup with the count. Scroll down to load more cards, then click it again to grab those too.

Only sends job title/company/location/URL for cards visible on the page — nothing else on the page, no credentials, no background access to your account.

View the bookmarklet's source (unminified, for your own review) 
(function () {
  const seen = new Set();
  const jobs = [];
  document.querySelectorAll('a[href*="/jobs/view/"]').forEach((a) => {
    const url = a.href.split('?')[0];
    if (seen.has(url)) return;
    const card = a.closest('li, div[data-occludable-job-id], .job-card-container, article') || a.parentElement;
    const text = (card ? card.innerText : (a.innerText || a.textContent || '')).trim();
    const lines = text.split('\n').map((s) => s.trim()).filter(Boolean);
    const title = (a.getAttribute('aria-label') || lines[0] || '').trim();
    if (!title || title.length < 3) return;
    seen.add(url);
    jobs.push({ url, title, company: lines[1] || '', location: lines[2] || '' });
  });

  if (jobs.length === 0) {
    alert('Career Ops: no job listings found on this page. Open a LinkedIn Jobs search results page first.');
    return;
  }

  fetch('http://127.0.0.1:5177/api/import-linkedin', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ jobs }),
  })
    .then((r) => r.json())
    .then((data) => {
      alert('Career Ops: imported ' + (data.added || 0) + ' new job(s) of ' + jobs.length + ' found on this page.');
    })
    .catch(() => {
      alert('Career Ops: could not reach the dashboard. Make sure CareerOps.exe is running, then try again.');
    });
})();
